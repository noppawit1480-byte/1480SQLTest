## บทเรียน (เมนู "บทเรียน")
- 4 หลักสูตร: Beginner (14) · Intermediate (16) · Advanced (14) · Professional (18)
- แต่ละบท: วัตถุประสงค์ → เนื้อหา → **ตัวอย่าง SQL** พร้อมคำอธิบายทีละส่วนและ **ผลลัพธ์จริงจาก PostgreSQL** → ข้อผิดพลาดที่พบบ่อย (ผิด/ถูก) → แบบฝึกหัดท้ายบท → โน้ตส่วนตัว
- ปุ่ม **Try it** เปิดตัวอย่างใน Playground พร้อมฐานข้อมูลที่ถูกต้อง (ตัวอย่าง DDL/DML จะเปิดในโหมด Writable)
- **Bookmark** และ **โน้ต** ดูรวมได้ที่หน้าโปรไฟล์

## SQL Playground
```
[Database Explorer] | [Toolbar: Run · Format · Clear · Save · Read-only/Writable · Reset]
                    | [SQL Editor]
                    | [ผลลัพธ์ | History | Saved]
```
- **Run**: ปุ่ม Run หรือ `Ctrl/⌘ + Enter` — รันได้หลายคำสั่งคั่นด้วย `;` ผลของแต่ละคำสั่งแสดงเป็นแท็บ
- **Autocomplete**: พิมพ์ชื่อตาราง/คอลัมน์/ฟังก์ชัน หรือพิมพ์ `alias.` เพื่อดูคอลัมน์ของตารางนั้น (`Ctrl + Space` เรียกเอง)
- **Syntax validation**: เส้นใต้สีแดงขณะพิมพ์ ตรวจด้วย parser ของ PostgreSQL จริง
- **Error**: แสดงข้อความ, SQLSTATE, บรรทัด/คอลัมน์ และ marker ใน editor
- **Database Explorer**: คลิกชื่อตารางเพื่อดูคอลัมน์ (🔑 PK, 🔗 FK, ·NN = NOT NULL), ไอคอนตาเพื่อ Preview ข้อมูล, คลิกชื่อคอลัมน์เพื่อแทรกลง editor
- **โหมด**
  - *Read-only* (ค่าเริ่มต้น): ฐานข้อมูลกลาง แก้ไขอะไรไม่ได้ — เหมาะกับฝึก SELECT
  - *Writable* (ต้อง login): ฐานข้อมูล **ส่วนตัว** ของคุณ ทำ INSERT/UPDATE/DELETE/CREATE/ALTER/DROP/Transaction ได้ — กด **Reset** เพื่อคืนค่าเริ่มต้น
- **History** บันทึกอัตโนมัติ · **Saved** บันทึก query ที่ใช้บ่อย
- ข้อจำกัด: query ละไม่เกิน 5 วินาที, แสดงไม่เกิน 1,000 แถว, SQL ไม่เกิน 20,000 ตัวอักษร / 50 คำสั่ง

## แบบฝึกหัด
1. เลือกโจทย์จากรายการ (กรองตามระดับ/หมวด/สถานะ)
2. อ่านโจทย์และ **Expected Result** · ดู schema ได้ที่แท็บ "Schema"
3. **Run** เพื่อดูผลของตัวเอง → **Submit** เพื่อตรวจ
4. ติดขัด? เปิด **Hint 1 → 2 → 3** ทีละขั้น (คำใบ้ → แนวทาง → keywords) ก่อนกด **Show Solution**

### ระบบตรวจคำตอบ
ตรวจจาก **ผลลัพธ์** ไม่ใช่ข้อความ SQL — เขียนต่างจากเฉลยได้ ขอให้ผลเหมือนกัน
| ตรวจ | รายละเอียด |
|---|---|
| คอลัมน์ | จำนวนและชื่อ (ไม่สนตัวพิมพ์) ตามลำดับ — ใช้ `AS` ตั้งชื่อให้ตรงโจทย์ |
| จำนวนแถว | ต้องเท่ากัน |
| ค่า | `NULL` ≠ `0` ≠ `''`; ตัวเลขเทียบที่ทศนิยม 2 ตำแหน่ง; ข้อความกับตัวเลขถือว่าคนละชนิด |
| ค่าซ้ำ | นับจำนวนครั้งที่ซ้ำด้วย (ลืม/เกิน DISTINCT จะผิด) |
| ลำดับแถว | ตรวจเฉพาะโจทย์ที่มีข้อความ "⚠ โจทย์นี้ตรวจลำดับของแถวด้วย" |
| โจทย์ DML/DDL | รันคำตอบบน **สำเนาฐานข้อมูลใหม่** แล้วตรวจสภาพข้อมูลด้วย query ตรวจสอบ — ไม่กระทบ Writable sandbox ของคุณ |

หลัง Submit จะเห็น Correct/Incorrect, เหตุผลที่ผิด, แถวที่หาย/เกิน, ตารางเปรียบเทียบ, คำอธิบาย และเฉลยตัวอย่าง (คะแนนให้ครั้งแรกที่ทำถูกเท่านั้น)

## Real-World Projects (เมนู Projects)
รับบทนักวิเคราะห์ในสถานการณ์ธุรกิจ 6 โปรเจกต์: Sales, Customer, Product, Employee, Financial และ **SaaS Metrics** (ฐานข้อมูลขั้นสูง)
1. อ่าน **Business Brief** — มี *นิยาม* ที่ต้องใช้ให้ตรง (เช่น สถานะคำสั่งซื้อที่นับเป็นยอดขาย)
2. ทำ **งาน** ทีละข้อ (ทุกงานตรวจอัตโนมัติจากผลลัพธ์เหมือนแบบฝึกหัด, มี Hint และเฉลย)
3. ผ่านครบทุกงาน → โปรเจกต์สำเร็จ + Achievement *Real-World Analyst* (ครบทุกโปรเจกต์ → *Project Master*)

## SQL Learning Assistant (แท็บ Assistant ใน Playground / แบบฝึกหัด และเมนู Assistant)
| โหมด | ทำอะไร | ต้องมี AI? |
|---|---|---|
| **Explain** | อธิบาย SQL ทีละส่วนตามลำดับที่ฐานข้อมูลประมวลผลจริง | ไม่ |
| **Explain Error** | อธิบาย error ล่าสุด พร้อมเดาชื่อตาราง/คอลัมน์ที่น่าจะพิมพ์ผิด | ไม่ |
| **Fix** | แนวทางแก้ไข (ในแบบฝึกหัด: ชี้จุดผิด ไม่เฉลย) | ไม่ |
| **Review** | ตรวจกับดักที่พบบ่อย: `= NULL`, `NOT IN` + NULL, LEFT JOIN ที่กลายเป็น INNER, `LIMIT` ไม่มี `ORDER BY`, `UPDATE/DELETE` ไม่มี WHERE ฯลฯ | ไม่ |
| **Optimize** | อ่าน execution plan จริง (EXPLAIN) แนะนำ index และการเขียนแบบ sargable | ไม่ |
| **AI เสริม** (checkbox) | เพิ่มคำอธิบายจาก AI ต่อจากผลวิเคราะห์ | ใช่ |
| **ถาม Tutor** | แชตถามเรื่อง SQL โดย Tutor เห็น schema ของฐานข้อมูลที่เลือก | ใช่ |
| **ควรฝึกอะไรต่อ** (หน้า Assistant) | หมวดที่คุณทำได้น้อยที่สุด + โจทย์ถัดไปที่แนะนำ | ไม่ |
| **สร้างโจทย์ฝึกเพิ่ม** (หน้า Assistant) | AI สร้างโจทย์ตามหัวข้อ — ระบบรันเฉลยบนฐานข้อมูลจริงก่อน แล้วตรวจคำตอบของคุณแบบเดียวกับโจทย์หลัก (ไม่นับคะแนน) | ใช่ |

> AI เป็นผู้ช่วยเสริมเท่านั้น — การตัดสินว่าคำตอบถูกหรือผิดมาจากการรันบนฐานข้อมูลจริงเสมอ · ในหน้าแบบฝึกหัด AI ไม่ได้รับเฉลยของโจทย์จึงเฉลยให้ไม่ได้ · ถ้าเซิร์ฟเวอร์ไม่ได้ตั้งค่า AI ฟีเจอร์ที่ต้องใช้ AI จะแสดงสถานะชัดเจน ส่วนโหมดอื่นใช้งานได้ตามปกติ

## Admin Panel (เฉพาะผู้ดูแลระบบ — เมนู Admin)
- **ภาพรวม**: ผู้ใช้, active วันนี้/7 วัน, การส่งคำตอบ, โจทย์ที่ผู้เรียนติดมากที่สุด, การใช้ Assistant
- **ผู้ใช้**: ค้นหา เปลี่ยน role ระงับ/เปิดใช้บัญชี (ระงับแล้ว session ถูกยกเลิกทันที)
- **บทเรียน / โจทย์ / Projects**: เพิ่ม แก้ไข ลบ — ทุกครั้งที่บันทึก ระบบ **รัน SQL ตัวอย่างและเฉลยบนฐานข้อมูลจริง** ถ้ารันไม่ผ่านจะไม่บันทึกและแจ้งเหตุผล; ปุ่ม “ทดสอบเฉลย” ดูผลลัพธ์ที่คาดหวังก่อนบันทึก
- เนื้อหาที่แก้ใน Admin จะ **ไม่ถูก seed ทับ**; บทเรียนหลักกด “คืนค่าจาก repository” ได้
- **Achievements**: แก้ชื่อ/คำอธิบาย/ไอคอน · **ฐานข้อมูล**: Rebuild template + คำนวณ expected ใหม่
